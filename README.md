# CUDA-Accelerated Deep Learning Inference Engine

This project implements a high-performance inference engine using **C++**, **CUDA**, **TensorRT**, and **cuBLAS** for **NVIDIA Jetson** platforms.

## 🚀 Features
- Mixed-precision inference (FP32/FP16/INT8)
- Custom CUDA kernels for activation and fusion layers
- TensorRT ONNX parsing and optimization
- cuBLAS for matrix operations
- Nsight-compatible profiling support
